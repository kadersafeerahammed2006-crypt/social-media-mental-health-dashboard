# Social Media Mental Health Dashboard

An interactive web-based analytics dashboard designed to explore social media usage patterns and their relationship with mental health indicators.

## Project Overview

The Social Media Mental Health Dashboard analyzes social media usage data and presents meaningful insights through interactive visualizations. It aims to help users understand usage patterns and explore potential associations between social media habits and mental health indicators.

## Key Features

- Interactive data analytics dashboard
- Social media usage pattern analysis
- Mental health indicator exploration
- Data visualization and graphical insights
- Structured data management
- User-friendly web interface

## Technology Stack

- **Programming Language:** Python
- **Backend Framework:** Flask
- **Data Analysis:** Pandas
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript
- **Visualization:** Data visualization libraries

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/social-media-mental-health-dashboard.git
```

### 2. Navigate to the Project

```bash
cd social-media-mental-health-dashboard
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```
